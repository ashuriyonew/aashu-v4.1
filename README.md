# Aashu Birthday V3 ✦

Advanced cinematic birthday microsite for Aashu.

Features:
- Animated night sky, aurora, moon and floating emoji/stickers
- Live countdown to 16 September 2026, 00:00 IST
- Animated memory wall
- Emoji orbit
- Interactive gift
- Typewriter letter signed Rɪʏᴀɴ 🎀
- 4 arcade games: Star Catch, Heart Tap, Memory Match, Lucky Box
- Achievement board and wish orb
- Canvas fireworks and cinematic ending
- Mobile responsive

Put your own or royalty-free MP3 at `assets/music/birthday.mp3`.

Deploy as a Render Static Site with publish directory `.`.
